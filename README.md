# Диагностика ПТСР по малоканальной сухой ЭЭГ

Командное решение трека «Нейродиагностика» (Пироговский Университет) в рамках хакатона &lt;!-- TODO: название и даты хакатона --&gt;.

&gt; **Статус публикации.** Репозиторий выложен в учебно-портфолио целях с согласия всех соавторов. Данные хакатона в репозитории отсутствуют и не распространяются (см. раздел «Данные»).

## Задача

Построить модель, которая по записи малоканальной сухой ЭЭГ (6 электродов) и результатам проб с таблицами Шульте оценивает вероятность посттравматического стрессового расстройства (ПТСР), и проверить её по техническому заданию трека: устойчивость к конфаундерам (возраст, соматоформные расстройства), интерпретируемость, специфичность.

## Данные

- Записи ЭЭГ 229 испытуемых в формате EDF: контроль (130), ПТСР (25), соматоформные расстройства (74).
- Данные принадлежат организаторам хакатона и были предоставлены участникам через открытое хранилище &lt;!-- TODO: ссылка на бакет, если организаторы не против --&gt; на время соревнования.
- **В этом репозитории данных нет.** Все записи анонимизированы организаторами (коды испытуемых вместо имён), но мы не считаем возможным их перераспространять: условия использования определяются правообладателем и условиями соревнования.
- Для воспроизведения анализа необходим доступ к исходному набору EDF.

## Что сделано

1. **Аудит качества данных.** Контрольная группа оказалась неоднородной: выделены четыре когорты (нормальная, артефактная, «только покой», 60+) по объективному правилу — структура файлов и возраст, без использования ЭЭГ-признаков. Найдены пустые и слишком короткие файлы, дубли записей, испытуемые под двумя кодами.
2. **Сравнение пяти моделей-кандидатов** (логистическая регрессия с отбором признаков, вложенный подбор гиперпараметров) по схеме leave-one-subject-out (LOSO) с поправкой вероятностей на долю классов.
3. **Проверка конфаундеров по ТЗ:** возраст, поведенческие показатели, технические конфаундеры (чувствительность признаков к квантованию сигнала), разбор ошибок.
4. **Физиологическая интерпретация** весов итоговой модели и проверка различий групп с поправкой на множественные сравнения.
5. **Бонусное задание:** восстановление разметки метронома и поиск отклика на девиантный стимул (MMN-подобный ответ). Отклик не обнаружен ни в одной из групп (p = 0,86) — вероятно, из-за ограничений 6-канальной сухой ЭЭГ и коротких записей.

## Основные результаты

- Итоговая модель: М1 — только признаки ЭЭГ покоя (124 признака, отобрано 10), LOSO AUC против всего контроля **0,83 [0,75; 0,89]**, доля ложноположительных среди соматоформных — 2,7 %, среди 60+ — 0 %.
- **Ключевой негативный результат:** ЭЭГ покоя сама по себе не отличает ПТСР от здоровых людей с качественными записями — против «нормальной» когорты контроля AUC ≈ 0,46–0,50, то есть на уровне случайного угадывания. Высокая итоговая метрика держится на том, что модель безошибочно распознаёт артефактную партию записей контроля.
- Время решения таблиц Шульте содержит настоящий сигнал (пациенты с ПТСР решают медленнее), но непригодно для пожилых: они решают ещё медленнее, и модель с суммарным временем массово ошибается на 60+.
